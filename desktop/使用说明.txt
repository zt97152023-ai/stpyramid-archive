STPyramid 桌面版 · Windows x64

1. 将压缩包完整解压到有写入权限的目录，双击 STPyramid.exe。
2. 在「压缩归档」中选择模式。Count＋图像选择 TIFF 和 H5AD，JSON 附件可选。
   仅图像模式使用快速融合版，选择 TIFF 即可。
3. 选择输出目录并确认归档名称。每个样本输出一个“样本名.stpyramid”目录。
   依次加入任务后点击「开始队列」。程序会在输出正式归档前执行无损核验。
4. 在「核验与恢复」中选择含 manifest.json 的归档目录。核验或恢复任务也从队列启动。
   恢复一体化包会写出原生分层 TIFF、H5AD 和随包保存的附件。

完整包大小是归档内所有文件的物理字节数。压缩过程还需要额外空间存放中间文件。
成功任务默认清理本程序生成的临时目录。若发生错误，日志会给出保留的临时目录。
已有归档和恢复目标目录需要换一个新名称。原始 TIFF、H5AD 与 JSON 保持原位。

当前版本支持 Windows x64。远期归档若绑定了不同版本的解码器，可在「核验与恢复」
中填写与该归档匹配的运行时根目录，其中应包含 089、091、hf 三个子目录。
